Authorized staff actions

Provide the token configured in Flask as HOSPITAL_STAFF_TOKEN.

The token is stored in this browser only. Without a configured server token, real-room updates and alert actions are disabled. ESP32 ingestion requires the server's HOSPITAL_DEVICE_TOKEN as the X-Device-Token header.
